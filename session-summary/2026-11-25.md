## 3. Technical Learnings
- **286947 vs 286335:** the 02-04 Audit Committee agenda lists the OCA03356 cover report as **286335**. Our 286947 has the same title (per `manifest.csv`), but it isn't on the agendas for 02-04, 02-17, 02-18 or 02-25. Where 286947 sits is unknown. Attachments may be re-posted under new ids when an item moves to another meeting, so the crawler should expect one title under several ids.
- **The extracted text puts every word on its own line.** `text/286947.txt` is one word per line, separated by `\n \n`. Check `src/ingest_pdf.py` extraction (pypdf layout? word spacing?) before building FTS on it: phrase search and passages will suffer. Unchecked for the other 5 files.
- **Scans:** a document is a scan when `manifest.csv` has `scanned=1` and `text_bytes=0` (only 295439 so far). Signed bylaws are probably scans as a rule. The scoped command line should report them as `no_text: scan`, separately from "not acquired". That isn't written into `docs/SCOPE.md` or `TODO.md` yet.
- **Finding attachments for a report number:**
  1. POST the calendar endpoint (S2 §3) for the date range.
  2. Fetch the agenda HTML of the matching meeting.
  3. Match `<a ...DocumentId=N>title</a>`, stripping inner tags (the title sits inside nested markup).
  - Scratch: `/tmp/claude-1000/-home-opc-civic-docs-index/f5798ae5-6d9d-484d-aebb-eb6ce2cc3a10/scratchpad/oca/`. It's disposable, with no KEEP file.
- **CI:** `gh pr checks` right after a push can show the *previous* run as pass. Use `gh run list --branch <b>` and check that `headSha` matches the pushed commit.
